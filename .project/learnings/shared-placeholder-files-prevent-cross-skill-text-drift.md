The {maturity_legend} pattern — a shared reference file (maturity-legend.md) interpolated via placeholder at runtime — emerged during plan refinement as a better alternative to copy-pasting legend text into multiple preambles. The pattern applies to any cross-skill text that must stay identical: create the shared file, reference it via placeholder, let each orchestrator fill it at runtime. This was not in the original plan; reviewers surfaced it as an IMPORTANT issue.
