# Epic Goal: initial

Build a suite of Claude Code skills implementing the structured development workflow defined in `workflow.md`. The skills manage state in `.project/` files so any session can pick up where a previous one left off, the right context is always available, and the developer only needs to make decisions, not manage state.

Skills built: `/create-epic`, `/explore`, `/create-architecture`, `/create-slices`, `/create-plan`, `/complete`, `/project-status`, `/refine-architecture`, `/audit-architecture`, `/refine-slices`. Existing `/refine-plan` and `/implement-plan` skills are reused as-is.
