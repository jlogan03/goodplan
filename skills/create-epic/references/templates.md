# Start Project Templates

## idea.md Template

```markdown
# Project Idea

## Problem
What problem exists and why it matters.

## Desired Outcome
What success looks like when the project is done.

## Scope
What is included, and explicitly what is out of scope.

## Constraints
Technical, timeline, resource, or other constraints that shape decisions.

## Open Questions
Unknowns that need to be resolved before or during development.
```

Write substantive content synthesized from the conversation — never leave placeholder text.

## CLAUDE.md Project Context Section

```markdown
## Project Context

Read these before doing any significant work in this repo:

- `.goodplan/idea.md` — project goal, scope, constraints
```

Later skills append additional references under this header as those files are created.
